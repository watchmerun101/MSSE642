# MSSE 642: Security Engineering

## Course Overview

This course focuses on **real-world security engineering skills** with practical, hands-on projects rather than traditional academic papers. You will build a comprehensive portfolio of security work including penetration testing environments, threat analyses, vulnerability testing, and security research.

## Course Format

- **Delivery**: Project-based and practical exercises
- **Submission Method**: All work submitted to GitHub in Markdown format
- **Collaboration**: Work in groups of 2-3 students
- **Communication**: Discussions held in Slack as topics arise
- **AI Tools**: Encouraged to use AI tools and automation for assignments

## Assignment Structure

There are three types of assignments throughout the course:

### 1. Projects (4 Total - Due on Even Weeks)

| Week | Project | Description |
|------|---------|-------------|
| **Week 2** | **Project 1** | Pen Testing Environment Setup<br>Deploy Kali Linux VM + Vulnerable Application VM<br>Group work - 3 people |
| **Week 4** | **Project 2** | Threat Analysis<br>Comprehensive threat modeling and risk assessment<br>Group or small group work |
| **Week 6** | **Project 3** | Application Security Testing<br>Test and improve applications for vulnerabilities<br>Applies Security Testing Guide methodologies |
| **Week 8** | **Project 4** | Advanced Testing Continuation<br>Extended Project 3 with advanced scenarios<br>Final security improvements and hardening |

### 2. Vibe Coding Vulnerability Analysis Projects (3 Total - Ongoing)

Security vulnerability analysis exercises performed throughout the course:

- **Weekly Component**: Each week includes security vulnerability analysis
- **Focus**: Identify, analyze, and document vulnerabilities
- **Practice**: Hands-on testing and code review
- **Interaction**: Test AI tools' ability to detect and fix vulnerabilities
- **Portfolio Building**: Build real security testing experience

### 3. Final Presentation (Week 7-8)

- **Format**: In-class presentation OR 5-minute video with PowerPoint
- **Content**: Comprehensive presentation of all three projects and security analyses
- **Replaces**: Traditional final exam
- **Deliverables**: Presentation slides, supporting documentation, technical appendices

### Markdown Format
