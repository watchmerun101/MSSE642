# Week 4: Project 2 - Threat Analysis

## Purpose
Conduct a comprehensive threat analysis to identify, assess, and prioritize security threats for an application or system.

## Objectives
- Identify potential threats and attack vectors
- Assess threat likelihood and impact
- Create threat models using industry frameworks
- Develop mitigation strategies
- Document findings in a formal threat analysis report

## Threat Analysis Framework
- **Asset Identification**: Identify valuable systems and data
- **Threat Identification**: Determine potential threats
- **Vulnerability Assessment**: Identify weaknesses that threats can exploit
- **Risk Evaluation**: Assess probability and impact
- **Recommendations**: Propose controls and mitigations

## Project Deliverables
- Threat model documentation
- Risk assessment matrix
- Attack surface analysis
- Mitigation strategies
- Formal threat analysis report

## Group Assignment
Work in small groups to:
- Select target system/application
- Identify stakeholders and assets
- Map threat actors and their capabilities
- Document attack scenarios
- Present findings

## Methodologies
- STRIDE (Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, Elevation of Privilege)
- PASTA (Process for Attack Simulation and Threat Analysis)
- Threat tree analysis
- Data flow diagram analysis

## Deliverables Due
End of Week 4 - Complete threat analysis report with recommendations
