# Week 6: Project 3 - Application Testing & Security

## Purpose
Work through security testing methodologies to test and improve multiple applications for security vulnerabilities, following established security testing frameworks and best practices.

## Objectives
- Apply systematic security testing approaches
- Test multiple applications or code modules
- Identify and document security issues
- Develop and validate security improvements
- Build secure development practices

## Project Scope
- Test 2-3 applications (self-coded or provided)
- Use established testing methodologies
- Perform both automated and manual testing
- Document all findings and remediation

## Testing Phases
1. **Planning**: Define scope and testing strategy
2. **Reconnaissance**: Gather information about the application
3. **Vulnerability Scanning**: Use automated tools to identify issues
4. **Manual Testing**: Conduct in-depth security testing
5. **Analysis**: Evaluate findings and prioritize risks
6. **Reporting**: Document vulnerabilities and recommendations

## Deliverables
- Security test plans
- Vulnerability assessment reports
- Code review findings
- Remediation recommendations
- Testing evidence and documentation

## Testing Framework
- OWASP Testing Guide methodology
- Security testing checklist
- Vulnerability classification system
- Risk rating system

## Applications to Test
- Include applications from Week 2 Pen Testing environment
- Develop new vulnerable applications for testing
- Reference "Sing book" security testing methodologies

This project continues into Weeks 7-8 with additional testing and final presentation preparation.
