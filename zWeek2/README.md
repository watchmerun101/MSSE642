# Week 2: Project 1 - Pen Testing Environment Setup

## Purpose
Set up a local penetration testing environment with a Kali Linux VM and a vulnerable application to practice security testing in a controlled environment.

## Objectives
- Deploy and configure Kali Linux virtual machine
- Set up a vulnerable application for testing
- Configure network communication between VMs
- Establish a safe testing environment for security exercises

## Project Deliverables
- **VM 1**: Kali Linux configured with penetration testing tools
- **VM 2**: Vulnerable application (self-coded or pre-built)
- Network configuration documentation
- Environment setup guide

## Requirements
- Virtual machine hypervisor (VirtualBox, VMware, or Hyper-V)
- Kali Linux ISO
- Vulnerable application (DVWA, WebGoat, or custom code)
- Adequate system resources (RAM, disk space)

## Activities
- Create and configure both virtual machines
- Install necessary penetration testing tools in Kali
- Deploy vulnerable application on second VM
- Test network connectivity between VMs
- Document the setup process

## Group Assignment
Work as a group to complete this project. Assign roles for:
- VM configuration
- Network setup
- Vulnerable app deployment
- Documentation
