# Vibe Coding Assignments

## Purpose
This folder tracks the security vulnerability analysis assignments (3 total) completed with practical coding and testing workflows.

## Assignment Model
The course guidance emphasizes ongoing vulnerability analysis with AI-assisted workflows and practical validation.

## Suggested Files
- vibe-coding-1.md
- vibe-coding-2.md
- vibe-coding-3.md

## Recommended Scope by Assignment
### Vibe Coding 1
- Baseline vulnerability identification
- Initial AI-assisted analysis prompts
- Initial remediation ideas

### Vibe Coding 2
- Deeper vulnerability testing
- Expanded exploitability assessment
- Validation of remediation changes

### Vibe Coding 3
- Advanced vulnerability and hardening analysis
- Comparative results before/after fixes
- Final lessons learned and reusable secure coding patterns

## Recommended Report Template
For each assignment, document:
- Objective and target
- Tools used
- Vulnerabilities found
- Severity and risk rationale
- Reproduction steps
- Remediation approach
- Verification after fix

- Weeks 1-2: Vibe Coding 1
- Weeks 3-4: Vibe Coding 2
- Weeks 5-6: Vibe Coding 3
