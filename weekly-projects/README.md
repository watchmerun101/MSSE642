# Weekly Projects

## Purpose
This folder centralizes documentation for the four major projects due on even-numbered weeks.

## Project Schedule
| Project | Due Week | Focus |
|---|---|---|
| Project 1 | Week 2 | Pen testing environment setup |
| Project 2 | Week 4 | Threat analysis |
| Project 3 | Week 6 | Application security testing |
| Project 4 | Week 8 | Advanced testing continuation |

## Expected Project Files
Use these file names for consistency:
- project-1-labsetup.md
- project-2-threat-analysis.md
- project-3-penlab-1.md
- project-4-penlab-2.md

## Recommended Content for Each Project File
- Scope and objectives
- Environment and tools
- Testing/analysis approach
- Findings
- Remediation actions
- Evidence (links to images)
- Conclusion and next steps

## Cross-Reference Guidance
- Week READMEs should point to the corresponding project file in this folder.
- Final presentation artifacts in research-presentation should summarize outcomes from all project files.
